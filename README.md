# IMD Rainfall Analysis

**Live page:** https://spandalai26.github.io/IMD-Rainfall-Analysis/Kerala/

## Kerala Climate Record

Seasonal rainfall (1901–2025) and temperature (1951–2025) trends for Kerala from
India Meteorological Department gridded data, comparing per-grid-cell and
state-average methods for ETCCDI-style indices.

- `index.html`: the published article (self-contained; open it directly or via GitHub Pages)
- `analysis/`: scripts to download the IMD data, compute the indices and rebuild the page

Data: India Meteorological Department, Pune. Rainfall grid: Pai et al. (2014), *Mausam* 65(1).
